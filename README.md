# Emoji en Escena

Juego interactivo en vivo para adivinar películas y series mediante secuencias de emojis y pistas. Incluye una consola privada para el presentador y una pantalla pública sincronizada para el escenario.

## Funcionalidades

- Control de preguntas, rondas, pistas y respuestas.
- Cronómetro configurable por pregunta.
- Gestión de equipos y marcador en vivo.
- Pantalla pública para proyección.
- Banco de preguntas con importación y exportación JSON.

## Requisitos

- Node.js (versión compatible con Vite 8).
- npm o Bun.

## Desarrollo local

```bash
git clone https://github.com/Afboi/emoji-en-escena.git
cd emoji-en-escena
npm install
npm run dev
```

## Scripts

- `npm run dev`: servidor local.
- `npm run build`: compilación de producción.
- `npm run lint`: análisis estático.
- `npm test`: pruebas automatizadas.

## Stack

React, TypeScript, TanStack Start/Router, Tailwind CSS, Supabase y Drizzle ORM.

## Configuración

Las variables de entorno se configuran localmente. No subir `.env` ni credenciales al repositorio.
